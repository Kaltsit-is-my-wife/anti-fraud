# 工具函数目录

## 文件概览

- `util.js`：常用时间与文本处理工具。
- `cloud.js`：云文件临时链接解析、云函数错误提示，以及云文件 URL 缓存。
- `permission.js`：管理端/审核端权限快照与页面访问校验。
- `cache.js`：轻量级本地缓存工具，提供 TTL 判断、读写缓存和刷新节流能力。
- `defaultVideos.js`：内置视频资源定义，给视频列表和详情页提供无需数据库也可展示的视频内容。

## 当前用途

- 首页、社区页、个人页使用 `cache.js` 做“先读缓存、再后台刷新”。
- `cloud.js` 会缓存云文件临时 URL，减少重复调用 `getTempFileURL`。
- 视频模块使用 `defaultVideos.js` 提供内置反诈视频，避免云端暂无内容时页面为空。
- 权限相关页面继续复用 `permission.js` 的快照能力。
