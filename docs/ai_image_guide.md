# AI 图片识别说明

本文档描述当前项目中 AI 图片识别能力的真实实现方式与部署要求。

---

## 1. 当前实现

AI 图片识别能力由 `cloudfunctions/aiChat` 提供。

当前实现特征：

- 前端在聊天页选择图片后，将图片转为 base64
- 云函数把图片和用户问题一起发送给通义千问多模态模型
- 返回诈骗风险分析结果
- 对话记录仅保存在本地，不写入数据库

当前代码入口：

- `pages/chat/chat.js`
- `cloudfunctions/aiChat/index.js`
- `cloudfunctions/aiChat/config.json`

---

## 2. 配置方式

AI Key 不再写死在代码中，而是通过云函数环境变量配置。

需要配置：

```json
{
  "QWEN_API_KEY": "sk-your-api-key-here",
  "QWEN_MODEL": "qwen-vl-plus"
}
```

默认模型：

- `qwen-vl-plus`

如需调整，可修改：

- `cloudfunctions/aiChat/config.json`
- 或云开发控制台中的环境变量

---

## 3. 部署步骤

1. 在微信开发者工具中打开 `cloudfunctions/aiChat`
2. 配置 `config.json` 或云函数环境变量
3. 右键 `aiChat` 文件夹
4. 选择“上传并部署：云端安装依赖”
5. 在云开发控制台确认超时时间至少为 20 秒

---

## 4. 使用方式

用户侧流程：

1. 打开 AI 聊天页
2. 点击图片按钮
3. 选择相册或拍照图片
4. 系统上传图片并发起分析
5. 返回诈骗风险判断与建议

适用内容：

- 诈骗聊天截图
- 转账页面截图
- 网页或 App 截图
- 含文字的可疑图片

---

## 5. 注意事项

- 如果未配置 `QWEN_API_KEY`，云函数会返回配置缺失错误
- 图片越清晰，模型分析越稳定
- 云函数图片分析比纯文字对话耗时更长
- 当前能力依赖多模态模型，不要再参考旧的 OCR 免费方案文档
