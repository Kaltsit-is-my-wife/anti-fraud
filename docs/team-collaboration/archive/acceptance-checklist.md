## 通用检查

- [ ] 修改文件已通过 JavaScript 语法检查。
- [ ] `git diff --check` 通过。
- [ ] 页面在微信开发者工具中可以编译。
- [ ] 控制台无新增关键错误。
- [ ] 云函数已部署到目标云环境。
- [ ] 变更已在 `CHANGELOG.md` 留痕。
- [ ] `CLAUDE.md`、CMS 文档或部署文档需要更新时已同步更新。

## 文章与 CMS

- [ ] CMS 草稿文章不出现在首页。
- [ ] CMS 草稿文章不出现在搜索。
- [ ] 通过已知 ID 不能打开草稿详情。
- [ ] 草稿不出现在相关文章。
- [ ] 已发布文章出现在首页。
- [ ] 已发布文章可被搜索。
- [ ] 已发布文章详情可打开。
- [ ] 文章封面图可以显示。
- [ ] 正文图片可以显示。
- [ ] 正文视频可以访问或播放。
- [ ] CMS 与小程序、数据库、媒体使用同一云环境。
- [ ] 首页文章缓存行为符合预期。
- [ ] 云端失败时本地演示内容显示明确提示。

## Banner

- [ ] 启用 Banner 可见。
- [ ] 禁用 Banner 不可见。
- [ ] Banner 按 `sort` 正确排序。
- [ ] `cloud://` 图片可以显示。
- [ ] HTTPS 图片可以显示。
- [ ] 无图片时背景色或渐变正常。
- [ ] 合法页面链接可以跳转。
- [ ] 无链接或非法链接不会造成页面报错。
- [ ] 云函数失败时本地 Banner 降级可用。
- [ ] 云端空列表不会错误显示旧内容。

## 视频

- [ ] 管理员可以创建视频。
- [ ] 视频可以保存为草稿。
- [ ] 草稿对普通用户不可见。
- [ ] 已发布视频对普通用户可见。
- [ ] 下线视频对普通用户不可见。
- [ ] 视频封面可以显示。
- [ ] 视频可以播放。
- [ ] 关联文章可以跳转。
- [ ] 关联话题可以跳转。
- [ ] 本地文件自动上传时可以回填资源地址。
- [ ] 上传取消、失败、权限不足和文件过大时有明确提示。
- [ ] 上传成功不会自动跳过草稿审核流程。

## 话题封面

- [ ] 新建话题可以选择图片或拍照。
- [ ] 上传成功后表单立即显示预览。
- [ ] 话题列表可以显示封面。
- [ ] 编辑已有话题可以回显封面。
- [ ] 清空封面后保存，数据库引用被清除。
- [ ] 保存时不会把 `coverImagePreview` 写入数据库。
- [ ] 云存储上传权限不足时有明确提示。
- [ ] 替换封面后确认旧文件清理策略已知晓。

## 权限

- [ ] 未登录用户访问管理页面有明确处理。
- [ ] 普通用户不能进入或操作管理页面。
- [ ] 普通用户直接调用管理云函数会被拒绝。
- [ ] `operator` 管理员可以执行授权的管理操作。
- [ ] `reviewer` 审核员只能执行授权的审核操作。
- [ ] 用户端接口不会返回管理字段或敏感数据。
