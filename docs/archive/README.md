# 历史归档文档

本目录用于存放已经完成阶段的历史规划、设计与实施说明。

这些文档保留的目的只有两个：

- 回溯历史版本设计与实现路径
- 为后续功能演进提供历史背景参考

使用原则：

- 不作为当前版本开发主依据
- 当前开发优先查看 `../README.md`、`../planning/improvement-backlog.md`、`../../README.md`、`../../ARCHITECTURE.md`
