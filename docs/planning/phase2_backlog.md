# 二期 Backlog

文档名称：`反诈卫士二期 Backlog`

适用项目：`反诈卫士` 微信小程序

用途：将二期需求拆成可执行任务，供研发排期、任务分配、测试准备使用。

关联文档：

- `docs/planning/phase2_requirements.md`
- `docs/planning/phase2_development_plan.md`
- `ARCHITECTURE.md`

---

## 1. 使用说明

本 Backlog 按以下维度拆分：

- 页面任务
- 云函数任务
- 数据表任务
- 审核与管理端任务
- 通用工程任务

每个任务包含：

- `ID`
- `优先级`
- `阶段`
- `依赖`
- `任务说明`
- `完成标准`

优先级说明：

- `P0`
  必须先做，否则主链路无法成立
- `P1`
  重要功能，影响二期完整交付
- `P2`
  可顺延，但最好在二期收口前完成

阶段说明：

- `A`
  内容升级阶段
- `B`
  互动与审核阶段
- `C`
  题库运营阶段

## 3. 数据表任务

## DB-01 文章内容块结构升级

- 优先级：`P0`
- 阶段：`A`
- 依赖：无
- 任务说明：
  为 `articles` 增加 `contentBlocks` 结构，用于支持图文混排。
- 完成标准：
  - 数据模型支持 `paragraph` / `image`
  - 旧文章可兼容读取
  - 新文章支持按块存储

## DB-02 热点话题模型

- 优先级：`P0`
- 阶段：`A`
- 依赖：无
- 任务说明：
  新增 `topics` 集合，承载官方热点话题。
- 完成标准：
  - 至少包含标题、摘要、封面图、内容块、状态、排序字段
  - 支持发布时间或生效时间字段

## DB-03 审核任务模型

- 优先级：`P0`
- 阶段：`B`
- 依赖：DB-02
- 任务说明：
  新增 `review_tasks` 集合，用于记录自动审核与人工审核状态。
- 完成标准：
  - 可记录目标对象、原始内容、命中词、自动审核结果、人工审核状态
  - 支持审核员、审核时间、审核原因

## DB-04 视频模型

- 优先级：`P1`
- 阶段：`A`
- 依赖：无
- 任务说明：
  新增 `videos` 集合，承载视频内容。
- 完成标准：
  - 支持标题、简介、封面图、视频地址、时长、分类、状态
  - 支持与文章、话题关联

## DB-05 题库模型

- 优先级：`P1`
- 阶段：`C`
- 依赖：无
- 任务说明：
  新增 `question_banks` 集合。
- 完成标准：
  - 支持题库名称、简介、封面图、状态、排序、题量统计

## DB-06 题目归属题库

- 优先级：`P1`
- 阶段：`C`
- 依赖：DB-05
- 任务说明：
  为 `quiz_questions` 增加 `bankId`。
- 完成标准：
  - 每道题可归属于一个题库
  - 抽题逻辑可按题库筛选

## DB-07 内容状态统一

- 优先级：`P0`
- 阶段：`B`
- 依赖：DB-03
- 任务说明：
  统一讨论内容状态字段。
- 完成标准：
  - 评论 / 回复至少支持 `pending_review`、`approved`、`rejected`、`hidden`
  - 前端展示仅消费允许状态
