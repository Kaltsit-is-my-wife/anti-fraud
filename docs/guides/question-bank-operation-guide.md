# 题库与题目导入操作指南

适用日期：2026-04-09

适用范围：当前“题目池 + 题库选题”版本

---

## 1. 先确认一件事

在开始操作前，先重新部署这批云函数：

- `getAdminQuestionBankList`
- `saveQuestionBank`
- `getQuestionBanks`
- `getQuizQuestionList`
- `saveQuizQuestion`
- `getQuizQuestions`
- `deleteQuestionBank`
- `importQuizQuestions`
- `updateQuestionBankRelation`
- `submitQuizAttempt`
- `initQuestionBanks`（如使用初始化/关联函数）

如果不先部署，页面和云函数版本对不上，会出现：

- 题目池为空
- 加入题库无效
- 按题库抽题不对
- 统计不对

---

## 2. 现在的逻辑是什么

当前不是“题目属于某一个题库”，而是：

- 所有题目先进入**题目池**
- 题库只是“从题目池里选题”
- 一道题可以被多个题库复用

所以你要记住：

1. 先有题目池
2. 再把题目加入某个题库

---

## 3. 三种常见操作

## 情况 A：新建一个题库，然后往里面批量导入新题

步骤：

1. 进入 `题库管理`
2. 新建题库并保存
3. 在这个题库对应的卡片上，点击 `批量导入`
4. 页面会跳到 `题目管理`
5. 顶部会显示你当前正在处理哪个题库
6. 直接把 JSON 数组粘贴到“批量导入到题目池”框里
7. 点击 `开始导入`

结果：

- 题目会先进入题目池
- 同时自动加入你当前这个题库

这是一种“新题导入并直接进题库”的方式。

---

## 情况 B：题目已经存在于题目池，现在要加入某个题库

步骤：

1. 进入 `题库管理`
2. 找到目标题库
3. 点击 `从题目池选题`
4. 进入 `题目管理`
5. 保持顶部显示的是这个题库
6. 在下方题目池列表里找到要加的题
7. 点击这道题右侧的 `加入当前题库`

结果：

- 题目不会被复制
- 只是和当前题库建立关联

如果想移除，就点 `移出当前题库`。

---

## 情况 C：只想把题目导入到题目池，不先放进任何题库

步骤：

1. 进入 `题库管理`
2. 点击顶部的 `查看题目池`
3. 进入 `题目管理`
4. 当前视图应是 `全部题目池`
5. 点击顶部的 `批量导入`
6. 粘贴 JSON
7. 点击 `开始导入`

结果：

- 题目只进入题目池
- 不会自动加入正式题库

之后如果需要，再切到某个题库，把这些题手动 `加入当前题库`。

---

## 4. 哪个入口该怎么用

在 `题库管理` 里：

- `从题目池选题`
  适合：已有题目，想把它们加入这个题库

- `新建题目`
  适合：新写一道题，并自动加入当前题库

- `批量导入`
  适合：一批新题导入，并自动加入当前题库

- `查看题目池`
  适合：管理全部题目，不针对某个具体题库

---

## 5. 批量导入文件格式

当前支持 JSON 数组。

标准格式示例：

```json
[
  {
    "question": "接到自称客服的退款电话时，最安全的做法是？",
    "options": [
      "按对方要求转账",
      "在原平台官方入口核实",
      "提供验证码配合退款",
      "下载对方发来的处理软件"
    ],
    "answerIndex": 1,
    "explanation": "退款应在原平台官方入口核实，不能提供验证码或转账。",
    "difficulty": 2,
    "tags": ["冒充客服", "退款"],
    "isActive": true
  }
]
```

字段说明：

- `question`：题干
- `options`：选项数组，2–6 个，对应 A–F
- `answerIndex`：正确答案索引，范围 `0`–`5`
- `explanation`：解析
- `difficulty`：难度，`1-5`
- `tags`：标签数组
- `isActive`：是否启用

示例文件位置：

- `docs/guides/question-bank-import-sample.json`

---

## 6. 导入成功后怎么检查

导入后检查这几件事：

1. 题目池列表里能看到新题
2. 如果你是从某个题库的 `批量导入` 进去的：
   - 新题右侧应该显示为 `移出当前题库`
   - 说明它已经加入这个题库
3. 回到 `题库管理`
   - 这个题库的题量统计会增加
4. 如果题库已发布：
   - 用户侧能从该题库抽到这些题

---

## 7. 最容易搞错的地方

### 错误 1：在“全部题目池”里导入，然后以为已经进了某个题库

不是。

在“全部题目池”里导入，只会进入题目池，不会自动进入某个正式题库。

要么：

- 从某个题库卡片上的 `批量导入` 进去导

要么：

- 导完后手动点击 `加入当前题库`

### 错误 2：看不到原来的 71 道题

这通常是因为云函数没重新部署，不是数据没了。

先重新部署本次清单里的云函数，再看题目池。

### 错误 3：题库发布失败

常见原因：

- 题库里启用题数不够
- 有启用题没写解析
- 有重复题

---

## 8. 推荐实际操作顺序

如果你是正常运营，建议这样做：

1. 先建题库
2. 再点 `批量导入`
3. 导入题目
4. 回题库页看统计
5. 预览答题
6. 没问题后发布

如果你是整理历史题目，建议这样做：

1. 先进 `查看题目池`
2. 看全部题目
3. 切到目标题库
4. 对需要的题点 `加入当前题库`

---

## 9. 一句话总结

你现在要这样理解：

- `题目池` 是总仓库
- `题库` 是从总仓库里选题的集合
- “导入”是把题放进总仓库
- “加入当前题库”是把仓库里的题挂到某个题库下

## 10. 本次 P0 修复后的验证

### 10.1 5/6 选项题

1. 新建一道 5 选项题，`answerIndex` 填 `4`（E），保存。
2. 在题库管理页点击“预览答题”，确认选项 A–E 完整显示，正确答案为 E，解析正确。
3. 发布题库，用普通账号进入答题，选择 E 交卷，确认判分正确。
4. 再新建一道 6 选项题，`answerIndex` 填 `5`（F），重复验证。
5. 尝试保存 7 个选项，确认提示“最多支持 6 个选项（A-F）”。
6. 如果题库中存在选项数或答案索引异常的历史题，发布时会被“选项或答案配置异常”阻止；用户侧抽题也会过滤这类题。

### 10.2 题库发布状态隔离

1. 新建一个草稿题库，加入至少 1 道启用题。
2. 普通账号直接调用 `getQuizQuestions`，传该草稿题库 ID，确认返回“题库不存在或未发布”。
3. 管理员用 `preview: true` 调用同一题库，确认可以预览。
4. 发布题库后，普通账号再调用，确认可以正常抽题。
5. 直接把题库改为 `offline`，普通账号交卷确认返回“题库不存在或未发布”。

### 10.3 超过 100 条题目

1. 在题目池准备超过 100 道启用题，分别加入测试题库。
2. 管理端题目列表确认能看到第 101 条之后的题目，并可编辑/停用。
3. 题库管理页确认启用题数与实际一致。
4. 发布校验不再因为只统计前 100 条而误判。
5. 用户侧连续抽题，确认能抽到第 101 条之后的题目。

### 10.4 权限

1. 普通用户调用 `getQuizQuestionList`、`saveQuizQuestion`、`deleteQuizQuestion`，确认返回“无管理权限”。
2. 普通用户调用 `getQuizQuestions` 并传 `preview: true`，确认返回“无管理权限，不能预览题库”。
